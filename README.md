# Dynamic Landscape Analysis of Cell Fate Decisions

Code reproducing the analyses and the global landscape model of:

> M. Fontaine, J.M. Delas, M. Saez, R.J. Maizels, E. Finnie, J. Briscoe, D.A. Rand (2025).
> *Dynamic Landscape Analysis of Cell Fate Decisions: Predictive Models of Neural
> Development From Single-Cell Data*. bioRxiv. https://doi.org/10.1101/2025.05.28.656648

The code covers: **single-cell RNA-seq analysis**, **flow cytometry analysis**,
and **global model simulation and fitting**.

The two appendices describe the methods reproduced here:

- **Appendix A — Data analysis:** https://doi.org/10.6084/m9.figshare.31342810
- **Appendix B — Modelling & estimation:** https://doi.org/10.6084/m9.figshare.31342816
